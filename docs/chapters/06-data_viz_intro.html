6  Introduction to Data Visualisation with ggplot2

7 Introduction

This chapter introduces data visualisation in R using ggplot2. By the end you will be able to build and customise plots layer by layer: scatter plots, bar charts, line plots, box plots, and histograms, with controlled axes, colours, themes, and labels for publication-ready figures.

8 Why Visualise Data?

Visualisation is not decoration — it is a core analytic tool. The brain processes visual information faster than text, and plots can reveal patterns that are invisible in raw numbers or summary tables.

Anscombe’s Quartet — Why Statistics Are Not Enough

Anscombe (1973) constructed four small datasets with identical summary statistics: same means, same standard deviations, same correlation, same regression line. The point: statistics alone can hide very different data structures.

data(anscombe)

anscombe_long <- anscombe |>
  dplyr::mutate(observation = dplyr::row_number()) |>
  tidyr::pivot_longer(cols = -observation,
                      names_to  = c(".value", "set"),
                      names_pattern = "(.)(.)")

# Summary statistics are identical across all four sets
anscombe_long |>
  dplyr::group_by(set) |>
  dplyr::summarise(

    mean_y      = round(mean(y), 2),

  flextable() |>
  flextable::set_caption("Summary statistics are IDENTICAL across all four Anscombe datasets.") |>
  flextable::theme_zebra() |>
  flextable::autofit()

9 Principles of Effective Visualisation

These few principles will save you from most common mistakes.

1. Be clear and informative. Every plot should answer a specific question. Give it a title and axis labels that stand alone — a reader should understand the plot without reading the surrounding text.

2. Represent data accurately. Don’t truncate the y-axis of a bar chart (bars must start at zero to compare lengths). Don’t use 3D effects. Don’t use areas or volumes to represent single numbers — people cannot compare them accurately.

3. Match visual encoding to data type. Position and length are the most accurate visual encodings; use them for the most important variable. Colour and shape are weaker — use them for secondary groupings.

4. Respect cognitive limits. Humans can distinguish about 7–8 categorical colours reliably. If you have more groups, consider faceting instead of adding more colours.

5. Design for your audience. A plot for a methods paper is not the same as a plot for a conference talk or a public report. Simpler is almost always better.

WarningThe Truncated Axis Trap

Starting a bar-chart y-axis above zero makes small differences look dramatic. A change from 48% to 52% should look like a 4-point change, not a doubling. If a difference is genuinely tiny but genuinely interesting, use dots and show the full range — don’t deceive with bar heights.

10 The Grammar of Graphics

ggplot2 is built on Leland Wilkinson’s Grammar of Graphics: the idea that every statistical plot can be described as a combination of a handful of components.

The components:

  1. Data — the data frame
  2. Aesthetics (aes()) — the mapping from data variables to visual properties (x position, y position, colour, size, shape)
  3. Geometries (geom_*()) — the shapes used to represent data (points, bars, lines, boxes)
  4. Scales — how values map to the visual range (axis limits, colour palettes)
  5. Facets — splitting into small-multiple sub-plots
  6. Themes — the non-data visual styling

A ggplot2 plot is built by adding these together with +:

ggplot(data = pdat, aes(x = Date, y = Prepositions, color = Region)) +
  geom_point() +
  geom_smooth(method = "lm") +
  facet_wrap(~ GenreRedux) +
  theme_bw() +
  labs(title = "My Plot")
TipWhy + and Not |>?

ggplot2 predates the pipe operator and uses + to add layers. The + matches the layering metaphor: each layer is an independent component you combine. You can still use |> to prepare the data, then switch to + to build the plot:

pdat |>
  dplyr::filter(Date > 1500) |>
  ggplot(aes(Date, Prepositions)) +
  geom_point()

12 Your First Plot

Let’s build a plot step by step.

Step 1: Initialise the Plot

ggplot(pdat, aes(x = Date, y = Prepositions))

We created an empty plotting area with defined axes but no visible data. We told ggplot which data to use (pdat) and defined the aesthetics (Date on x, Prepositions on y). No geometry layer yet, so nothing is drawn.

ImportantThe aes() Function

aes() stands for aesthetics. It maps data variables to visual properties:

  • aes(x = Date) → Date determines horizontal position
  • aes(y = Prepositions) → Preposition values determine vertical position
  • aes(color = Genre) → Genre determines colour
  • aes(size = Population) → Population determines point size
  • aes(shape = Treatment) → Treatment determines point shape

Critical distinction — inside aes() vs. outside:

# Inside aes() - colour varies by data variable
geom_point(aes(color = Region))

# Outside aes() - all points same fixed colour
geom_point(color = "blue")

Step 2: Add Points (Geometry Layer)

ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point()

Now we see data. Each point is one text. The + adds layers.

Step 3: Add a Trend Line

ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point() +
  geom_smooth(se = FALSE) +
  theme_bw()

geom_smooth() adds a smoothed trend line (LOESS by default). se = FALSE removes the confidence interval shading. theme_bw() applies a black-and-white theme.

Smoothing methods:

geom_smooth()                            # LOESS (default): local weighted regression
geom_smooth(method = "lm")               # straight linear regression line
geom_smooth(method = "gam")              # generalised additive model (smooth, faster)
geom_smooth(method = "lm", se = TRUE)    # with confidence interval shading

Step 4: Store Plots as Objects

Any plot can be assigned to a name and modified later:

# Store the base plot
p_base <- ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point() +
  theme_bw()

# Add labels later
p_base +
  labs(
    title    = "Preposition frequency over time",
    subtitle = "Penn Parsed Corpora of Historical English",
    x        = "Year",
    y        = "Prepositions per 1,000 words"
  )

Storing a plot as an object lets you reuse the base and try variations without rebuilding from scratch.

13 Common Plot Types

This section shows the most frequently used geoms. Each has many options — this is the starting point.

Scatter Plot — geom_point()

Scatter plots show the relationship between two numeric variables.

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  theme_bw() +
  labs(title = "Preposition frequency over time, by genre",
       x = "Year", y = "Prepositions per 1,000 words",
       color = "Genre")

Bar Chart — geom_bar() and geom_col()

geom_bar() counts observations in each category. geom_col() uses pre-computed values from the data.

# geom_bar: counts rows
ggplot(pdat, aes(x = GenreRedux)) +
  geom_bar(fill = "steelblue") +
  theme_bw() +
  labs(title = "Number of texts per genre", x = "Genre", y = "Count")
# geom_col: use a pre-computed mean
pdat |>
  dplyr::group_by(GenreRedux) |>
  dplyr::summarise(mean_prep = mean(Prepositions, na.rm = TRUE),
                   .groups = "drop") |>
  ggplot(aes(x = GenreRedux, y = mean_prep, fill = GenreRedux)) +
    geom_col() +
    theme_bw() +
    theme(legend.position = "none") +
    labs(title = "Mean preposition frequency by genre",
         x = "Genre", y = "Mean prepositions per 1,000 words")

Box Plot — geom_boxplot()

Box plots show the distribution of a numeric variable across groups: median, quartiles, whiskers (1.5 × IQR), and outliers.

ggplot(pdat, aes(x = GenreRedux, y = Prepositions, fill = GenreRedux)) +
  geom_boxplot(alpha = 0.7) +
  theme_bw() +
  theme(legend.position = "none") +
  labs(title = "Distribution of preposition frequency by genre",
       x = "Genre", y = "Prepositions per 1,000 words")

Histogram — geom_histogram()

Histograms show the distribution of a single numeric variable by binning values and counting observations in each bin.

ggplot(pdat, aes(x = Prepositions)) +
  geom_histogram(bins = 25, fill = "steelblue", color = "white") +
  theme_bw() +
  labs(title = "Distribution of preposition frequencies",
       x = "Prepositions per 1,000 words", y = "Count")

Line Plot — geom_line()

Line plots are for data with a meaningful ordering on the x-axis (often time). Combined with a grouping aesthetic, they show trends across categories.

# Mean prepositions per year, by region
pdat |>
  dplyr::group_by(Date, Region) |>
  dplyr::summarise(mean_prep = mean(Prepositions, na.rm = TRUE),
                   .groups = "drop") |>
  ggplot(aes(x = Date, y = mean_prep, color = Region)) +
    geom_line(linewidth = 1) +
    theme_bw() +
    labs(title = "Mean preposition frequency over time, by region",
         x = "Year", y = "Mean prepositions per 1,000 words",
         color = "Region")

Facet — Small Multiples

facet_wrap() splits a plot into sub-plots by a categorical variable. Often clearer than using too many colours.

ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point(alpha = 0.4, size = 1.5) +
  geom_smooth(method = "lm", se = FALSE, color = "red") +
  facet_wrap(~ GenreRedux) +
  theme_bw() +
  labs(title = "Preposition trends by genre",
       x = "Year", y = "Prepositions per 1,000 words")

14 Customising Axes and Titles

Titles and Labels — labs()

labs() is the recommended way to set every text label:

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6) +
  theme_bw() +
  labs(
    title    = "Preposition frequency over time, by genre",
    subtitle = "Historical English, 1150–1913",
    caption  = "Data: Penn Parsed Corpora of Historical English",
    x        = "Year",
    y        = "Prepositions per 1,000 words",
    color    = "Genre"       # legend title
  )
TipThe “Self-Contained” Test

Imagine your plot is reproduced in a tweet, a slide, or someone else’s paper, divorced from your text. Can a reader understand it from the title, labels, and legend alone? If not, your labels need work.

Axis Limits

There are two ways to set axis limits — and they do different things:

# Zoom (recommended) — keeps all data but changes what is visible
+ coord_cartesian(xlim = c(1500, 1900), ylim = c(0, 200))

# Clip — DROPS data outside the limits (statistics are recomputed)
+ scale_x_continuous(limits = c(1500, 1900))
+ scale_y_continuous(limits = c(0, 200))

The difference matters for geom_smooth(): coord_cartesian() draws the smooth over all the data and then zooms, while scale_*_continuous() drops data first and refits the smooth. Prefer coord_cartesian() unless you really want to filter.

Breaks and Labels

Control exactly where tick marks appear and what text they show:

ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point(alpha = 0.5) +
  scale_x_continuous(
    breaks = seq(1200, 1900, by = 100),
    labels = seq(1200, 1900, by = 100)
  ) +
  scale_y_continuous(
    breaks = seq(0, 250, by = 50)
  ) +
  theme_bw() +
  labs(x = "Year", y = "Prepositions per 1,000 words")

For currency, percentages, dates, or scientific notation, use the scales package:

scale_y_continuous(labels = scales::comma)        # 10,000
scale_y_continuous(labels = scales::dollar)       # $10,000
scale_y_continuous(labels = scales::percent)      # 42%
scale_y_continuous(labels = scales::scientific)   # 1.0e+04

Angled Axis Text

When x-axis labels overlap, rotate them:

ggplot(pdat, aes(x = Genre, y = Prepositions)) +
  geom_boxplot() +
  theme_bw() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1)) +
  labs(x = NULL, y = "Prepositions per 1,000 words")

angle = 45 with hjust = 1 is almost always the right choice — easier to read than vertical, and the labels align with the ticks.

15 Working with Colours

Mapping Colour to Data

Put colour inside aes() to map it to a variable:

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6) +
  theme_bw()

ggplot2 picks default colours automatically and adds a legend.

Colour vs. Fill

  • color controls points, lines, and borders
  • fill controls the inside of areas (bars, boxes, polygons)
geom_point(aes(color = category))              # points coloured
geom_bar(aes(fill = category))                 # bars filled
geom_bar(aes(fill = category), color = "black") # fill + black outline

Manual Colour Palettes

Choose your own colours with scale_color_manual() or scale_fill_manual():

my_colors <- c("Conversational" = "#E41A1C",
               "Fiction"        = "#377EB8",
               "Legal"          = "#4DAF4A",
               "NonFiction"     = "#984EA3",
               "Religious"      = "#FF7F00")

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  scale_color_manual(name = "Genre", values = my_colors) +
  theme_bw()

ColorBrewer Palettes

The RColorBrewer package provides carefully designed palettes for different data types (categorical, sequential, diverging):

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  scale_color_brewer(palette = "Set2") +
  theme_bw()

Viridis — Perceptually Uniform and Colour-Blind-Friendly

The viridis palettes are designed to be readable in grayscale and by people with colour-vision deficiencies. Use scale_color_viridis_d() for discrete data and scale_color_viridis_c() for continuous data:

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  scale_color_viridis_d(option = "D") +   # options: A, B, C, D, E
  theme_bw()
TipMatching Palette to Data Type
Data type Palette type Example
Unordered categories Qualitative (distinct hues) Set1, Set2
Ordered categories or continuous Sequential (single hue) Blues, viridis
Diverging (positive/negative) Diverging (two-colour) RdBu, BrBG

Using a sequential palette for unordered categories implies an order that is not there. Using a qualitative palette for ordered data wastes the ordering information.

16 Themes

Themes control the non-data elements of a plot: backgrounds, grid lines, text sizes, legend placement.

Built-in Themes

p_base <- ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point(alpha = 0.4)

# Each of the following themes can be added:
p_base + theme_bw()         # recommended default for publications
# p_base + theme_classic()   # L-shaped axes, no grid — some journals prefer
# p_base + theme_minimal()   # clean, modern — good for presentations
# p_base + theme_light()     # soft gray gridlines
# p_base + theme_void()      # no axes, grid, or background — for maps and art

Guidance: theme_bw() is a safe default for academic papers. theme_minimal() is often preferred for presentations and web reports. Avoid the ggplot2 default (theme_gray()) for finished output — the gray panel background doesn’t photocopy or print well.

Customising a Theme

Any theme element can be overridden with theme():

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  theme_bw() +
  theme(
    legend.position  = "bottom",
    plot.title       = element_text(size = 14, face = "bold"),
    plot.subtitle    = element_text(size = 11, color = "gray40"),
    axis.title       = element_text(size = 12),
    panel.grid.minor = element_blank()
  ) +
  labs(title = "Preposition frequency over time, by genre",
       subtitle = "Legend moved to bottom; minor gridlines removed",
       color = "Genre")

Common adjustments:

  • legend.position = "bottom" / "top" / "none" / c(0.1, 0.9) for a specific location
  • axis.text.x = element_text(angle = 45, hjust = 1) to rotate x-labels
  • panel.grid.minor = element_blank() to remove minor gridlines
  • strip.background = element_rect(fill = "gray90") to style facet labels

17 Saving Plots

ggsave() saves the most recently displayed plot (or a named plot object). It infers the format from the file extension:

# Save the last plot that was displayed
ggsave(
  filename = here::here("images", "prepositions_by_genre.png"),
  width    = 8,
  height   = 5,
  units    = "in",
  dpi      = 300
)

# Save a specific plot object
my_plot <- ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point() + theme_bw()

ggsave(
  plot     = my_plot,
  filename = here::here("images", "prepositions.pdf"),
  width    = 7,
  height   = 4
)

Guidance by output type:

Use Format DPI Notes
Journal paper PDF or TIFF 300+ Vector (PDF) best for line art; raster (TIFF) for photos
Presentation PNG 150 Keep file size reasonable for slides
Web / blog PNG or SVG 100–150 SVG scales but not all platforms support it
LaTeX document PDF — Vector; integrates cleanly

On dimensions: keep aspect ratio similar to what you want in the final document. A plot squeezed from 10×6 inches into a 3-inch column will look cramped — resize at generation time, not at insertion time.

18 Further Resources

This chapter covered the core workflow for building and customising ggplot2 plots. Topics not covered here but worth exploring:

  • Combining plots — the patchwork package lets you combine ggplot objects with +, |, and / operators
  • Text and annotations — geom_text(), geom_label(), annotate(), and the ggrepel package for non-overlapping labels
  • Legend fine-tuning — guides() for controlling multiple legends; theme(legend.*) for detailed styling
  • Advanced faceting — facet_grid() for two-variable facets; scales = "free" for independent axes
  • Interactive plots — plotly::ggplotly() converts a ggplot into an interactive HTML widget
  • Themes and extensions — the ggthemes package has journal-specific themes (Economist, FiveThirtyEight, etc.)

# Why Visualise Data? {#sec-dataviz-why}

Visualisation is not decoration — it is a core analytic tool. The brain processes visual information faster than text, and plots can reveal patterns that are invisible in raw numbers or summary tables.

## Anscombe's Quartet — Why Statistics Are Not Enough {-}

Anscombe (1973) constructed four small datasets with **identical** summary statistics: same means, same standard deviations, same correlation, same regression line. The point: statistics alone can hide very different data structures.

```{r anscombe_stats_dataviz, message=FALSE, warning=FALSE}
data(anscombe)

anscombe_long <- anscombe |>
  dplyr::mutate(observation = dplyr::row_number()) |>
  tidyr::pivot_longer(cols = -observation,
                      names_to  = c(".value", "set"),
                      names_pattern = "(.)(.)")

# Summary statistics are identical across all four sets
anscombe_long |>
  dplyr::group_by(set) |>
  dplyr::summarise(
    mean_x      = round(mean(x), 2),
    mean_y      = round(mean(y), 2),
    sd_x        = round(sd(x), 2),
    sd_y        = round(sd(y), 2),
    correlation = round(cor(x, y), 3),
    .groups     = "drop"
  ) |>
  flextable() |>
  flextable::set_caption("Summary statistics are IDENTICAL across all four Anscombe datasets.") |>
  flextable::theme_zebra() |>
  flextable::autofit()
```

Now plot them:

```{r anscombe_plot_dataviz, message=FALSE, warning=FALSE, fig.width=8, fig.height=6}
ggplot2::ggplot(anscombe_long, ggplot2::aes(x = x, y = y)) +
  ggplot2::geom_point(size = 2, colour = "steelblue") +
  ggplot2::geom_smooth(method = "lm", se = FALSE, colour = "red") +
  ggplot2::facet_wrap(~ set) +
  ggplot2::theme_bw() +
  ggplot2::labs(title = "Anscombe's Quartet: same statistics, very different data")
```

Set I is a reasonable linear relationship. Set II is a clear curve. Set III has a single outlier distorting a tight line. Set IV has one leverage point creating the whole regression. **Always plot your data.**

# Principles of Effective Visualisation {#sec-dataviz-principles}

These few principles will save you from most common mistakes.

**1. Be clear and informative.** Every plot should answer a specific question. Give it a title and axis labels that stand alone — a reader should understand the plot without reading the surrounding text.

**2. Represent data accurately.** Don't truncate the y-axis of a bar chart (bars must start at zero to compare lengths). Don't use 3D effects. Don't use areas or volumes to represent single numbers — people cannot compare them accurately.

**3. Match visual encoding to data type.** Position and length are the most accurate visual encodings; use them for the most important variable. Colour and shape are weaker — use them for secondary groupings.

**4. Respect cognitive limits.** Humans can distinguish about 7–8 categorical colours reliably. If you have more groups, consider faceting instead of adding more colours.

**5. Design for your audience.** A plot for a methods paper is not the same as a plot for a conference talk or a public report. Simpler is almost always better.

::: {.callout-warning}
## The Truncated Axis Trap

Starting a bar-chart y-axis above zero makes small differences look dramatic. A change from 48% to 52% should look like a 4-point change, not a doubling. If a difference is genuinely tiny but genuinely interesting, use dots and show the full range — don't deceive with bar heights.
:::

# The Grammar of Graphics {#sec-dataviz-grammar}

`ggplot2` is built on Leland Wilkinson's **Grammar of Graphics**: the idea that every statistical plot can be described as a combination of a handful of components.

**The components:**

1. **Data** — the data frame
2. **Aesthetics** (`aes()`) — the mapping from data variables to visual properties (x position, y position, colour, size, shape)
3. **Geometries** (`geom_*()`) — the shapes used to represent data (points, bars, lines, boxes)
4. **Scales** — how values map to the visual range (axis limits, colour palettes)
5. **Facets** — splitting into small-multiple sub-plots
6. **Themes** — the non-data visual styling

A `ggplot2` plot is built by adding these together with `+`:

```{r ggplot_concept_dataviz, eval=FALSE}
ggplot(data = pdat, aes(x = Date, y = Prepositions, color = Region)) +
  geom_point() +
  geom_smooth(method = "lm") +
  facet_wrap(~ GenreRedux) +
  theme_bw() +
  labs(title = "My Plot")
```

::: {.callout-tip}
## Why `+` and Not `|>`?

`ggplot2` predates the pipe operator and uses `+` to add layers. The `+` matches the layering metaphor: each layer is an independent component you combine. You can still use `|>` to prepare the data, then switch to `+` to build the plot:

```r
pdat |>
  dplyr::filter(Date > 1500) |>
  ggplot(aes(Date, Prepositions)) +
  geom_point()
```
:::

# Your First Plot {#sec-dataviz-firstplot}

Let's build a plot step by step.

## Step 1: Initialise the Plot {-}

```{r plot1-dataviz}
ggplot(pdat, aes(x = Date, y = Prepositions))
```

We created an empty plotting area with defined axes but no visible data. We told `ggplot` which data to use (`pdat`) and defined the aesthetics (`Date` on x, `Prepositions` on y). No geometry layer yet, so nothing is drawn.

::: {.callout-important}
## The `aes()` Function

`aes()` stands for **aesthetics**. It maps **data variables** to **visual properties**:

- `aes(x = Date)` → Date determines horizontal position
- `aes(y = Prepositions)` → Preposition values determine vertical position
- `aes(color = Genre)` → Genre determines colour
- `aes(size = Population)` → Population determines point size
- `aes(shape = Treatment)` → Treatment determines point shape

**Critical distinction — inside `aes()` vs. outside:**

```r
# Inside aes() - colour varies by data variable
geom_point(aes(color = Region))

# Outside aes() - all points same fixed colour
geom_point(color = "blue")
```
:::

## Step 2: Add Points (Geometry Layer) {-}

```{r plot2-dataviz}
ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point()
```

Now we see data. Each point is one text. The `+` adds layers.

## Step 3: Add a Trend Line {-}

```{r plot3-dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point() +
  geom_smooth(se = FALSE) +
  theme_bw()
```

`geom_smooth()` adds a smoothed trend line (LOESS by default). `se = FALSE` removes the confidence interval shading. `theme_bw()` applies a black-and-white theme.

**Smoothing methods:**

```{r smoothing_methods_dataviz, eval=FALSE}
geom_smooth()                            # LOESS (default): local weighted regression
geom_smooth(method = "lm")               # straight linear regression line
geom_smooth(method = "gam")              # generalised additive model (smooth, faster)
geom_smooth(method = "lm", se = TRUE)    # with confidence interval shading
```

## Step 4: Store Plots as Objects {-}

Any plot can be assigned to a name and modified later:

```{r plot_object_dataviz, message=FALSE, warning=FALSE}
# Store the base plot
p_base <- ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point() +
  theme_bw()

# Add labels later
p_base +
  labs(
    title    = "Preposition frequency over time",
    subtitle = "Penn Parsed Corpora of Historical English",
    x        = "Year",
    y        = "Prepositions per 1,000 words"
  )
```

Storing a plot as an object lets you reuse the base and try variations without rebuilding from scratch.

# Common Plot Types {#sec-dataviz-geoms}

This section shows the most frequently used geoms. Each has many options — this is the starting point.

## Scatter Plot — `geom_point()` {-}

Scatter plots show the relationship between two numeric variables.

```{r scatter_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  theme_bw() +

       x = "Year", y = "Prepositions per 1,000 words",
```

## Bar Chart — `geom_bar()` and `geom_col()` {-}

`geom_bar()` counts observations in each category. `geom_col()` uses pre-computed values from the data.

```{r bar_dataviz, message=FALSE, warning=FALSE}
# geom_bar: counts rows
ggplot(pdat, aes(x = GenreRedux)) +
  geom_bar(fill = "steelblue") +
  theme_bw() +
  labs(title = "Number of texts per genre", x = "Genre", y = "Count")
```

```{r col_dataviz, message=FALSE, warning=FALSE}
# geom_col: use a pre-computed mean
pdat |>
  dplyr::group_by(GenreRedux) |>

                   .groups = "drop") |>
  ggplot(aes(x = GenreRedux, y = mean_prep, fill = GenreRedux)) +
    geom_col() +
    theme_bw() +
    theme(legend.position = "none") +
    labs(title = "Mean preposition frequency by genre",
         x = "Genre", y = "Mean prepositions per 1,000 words")
```

## Box Plot — `geom_boxplot()` {-}

Box plots show the distribution of a numeric variable across groups: median, quartiles, whiskers (1.5 × IQR), and outliers.

```{r box_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = GenreRedux, y = Prepositions, fill = GenreRedux)) +
  geom_boxplot(alpha = 0.7) +
  theme_bw() +
  theme(legend.position = "none") +
  labs(title = "Distribution of preposition frequency by genre",
       x = "Genre", y = "Prepositions per 1,000 words")
```

## Histogram — `geom_histogram()` {-}

Histograms show the distribution of a single numeric variable by binning values and counting observations in each bin.

```{r hist_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Prepositions)) +
  geom_histogram(bins = 25, fill = "steelblue", color = "white") +
  theme_bw() +
  labs(title = "Distribution of preposition frequencies",
       x = "Prepositions per 1,000 words", y = "Count")
```

## Line Plot — `geom_line()` {-}

Line plots are for data with a meaningful ordering on the x-axis (often time). Combined with a grouping aesthetic, they show trends across categories.

```{r line_dataviz, message=FALSE, warning=FALSE}
# Mean prepositions per year, by region

  dplyr::group_by(Date, Region) |>
  dplyr::summarise(mean_prep = mean(Prepositions, na.rm = TRUE),
                   .groups = "drop") |>
```

# Customising Axes and Titles {#sec-dataviz-axes}

## Titles and Labels — `labs()` {-}

`labs()` is the recommended way to set every text label:

```{r labs_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6) +
  theme_bw() +
```

::: {.callout-tip}
## The "Self-Contained" Test

Imagine your plot is reproduced in a tweet, a slide, or someone else's paper, divorced from your text. Can a reader understand it from the title, labels, and legend alone? If not, your labels need work.
:::

## Axis Limits {-}

There are two ways to set axis limits — and they do different things:

```{r xlim_dataviz, eval=FALSE}
# Zoom (recommended) — keeps all data but changes what is visible
+ coord_cartesian(xlim = c(1500, 1900), ylim = c(0, 200))

# Clip — DROPS data outside the limits (statistics are recomputed)
+ scale_x_continuous(limits = c(1500, 1900))
+ scale_y_continuous(limits = c(0, 200))
```

The difference matters for `geom_smooth()`: `coord_cartesian()` draws the smooth over all the data and then zooms, while `scale_*_continuous()` drops data first and refits the smooth. Prefer `coord_cartesian()` unless you really want to filter.

## Breaks and Labels {-}

Control exactly where tick marks appear and what text they show:

```{r breaks_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point(alpha = 0.5) +
  scale_x_continuous(
    breaks = seq(1200, 1900, by = 100),
    labels = seq(1200, 1900, by = 100)
  ) +
  scale_y_continuous(
    breaks = seq(0, 250, by = 50)
  ) +
  theme_bw() +
  labs(x = "Year", y = "Prepositions per 1,000 words")
```

For currency, percentages, dates, or scientific notation, use the `scales` package:

```{r scales_formatters_dataviz, eval=FALSE}
scale_y_continuous(labels = scales::comma)        # 10,000
scale_y_continuous(labels = scales::dollar)       # $10,000
scale_y_continuous(labels = scales::percent)      # 42%
scale_y_continuous(labels = scales::scientific)   # 1.0e+04
```

## Angled Axis Text {-}

When x-axis labels overlap, rotate them:

```{r angled_text_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Genre, y = Prepositions)) +
  geom_boxplot() +
  theme_bw() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1)) +
  labs(x = NULL, y = "Prepositions per 1,000 words")
```

`angle = 45` with `hjust = 1` is almost always the right choice — easier to read than vertical, and the labels align with the ticks.

# Working with Colours {#sec-dataviz-colors}

## Mapping Colour to Data {-}

Put colour **inside** `aes()` to map it to a variable:


`ggplot2` picks default colours automatically and adds a legend.

## Colour vs. Fill {-}

- `color` controls points, lines, and borders
- `fill` controls the inside of areas (bars, boxes, polygons)

```{r color_vs_fill_dataviz, eval=FALSE}
geom_point(aes(color = category))              # points coloured
geom_bar(aes(fill = category))                 # bars filled
geom_bar(aes(fill = category), color = "black") # fill + black outline
```

## Manual Colour Palettes {-}

Choose your own colours with `scale_color_manual()` or `scale_fill_manual()`:

```{r manual_colors_dataviz, message=FALSE, warning=FALSE}
my_colors <- c("Conversational" = "#E41A1C",
               "Fiction"        = "#377EB8",
               "Legal"          = "#4DAF4A",
               "NonFiction"     = "#984EA3",
               "Religious"      = "#FF7F00")

ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  scale_color_manual(name = "Genre", values = my_colors) +
  theme_bw()
```

## ColorBrewer Palettes {-}

The `RColorBrewer` package provides carefully designed palettes for different data types (categorical, sequential, diverging):

```{r brewer_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  scale_color_brewer(palette = "Set2") +
  theme_bw()
```

## Viridis — Perceptually Uniform and Colour-Blind-Friendly {-}

The `viridis` palettes are designed to be readable in grayscale and by people with colour-vision deficiencies. Use `scale_color_viridis_d()` for discrete data and `scale_color_viridis_c()` for continuous data:

```{r viridis_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  scale_color_viridis_d(option = "D") +   # options: A, B, C, D, E
  theme_bw()
```

::: {.callout-tip}
## Matching Palette to Data Type

| Data type | Palette type | Example |
|-----------|--------------|---------|
| Unordered categories | Qualitative (distinct hues) | `Set1`, `Set2` |
| Ordered categories or continuous | Sequential (single hue) | `Blues`, `viridis` |
| Diverging (positive/negative) | Diverging (two-colour) | `RdBu`, `BrBG` |

Using a sequential palette for unordered categories implies an order that is not there. Using a qualitative palette for ordered data wastes the ordering information.
:::

# Themes {#sec-dataviz-themes}

Themes control the non-data elements of a plot: backgrounds, grid lines, text sizes, legend placement.

## Built-in Themes {-}

```{r themes_dataviz, message=FALSE, warning=FALSE, fig.width=10, fig.height=4}
p_base <- ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point(alpha = 0.4)

# Each of the following themes can be added:
p_base + theme_bw()         # recommended default for publications
# p_base + theme_classic()   # L-shaped axes, no grid — some journals prefer
# p_base + theme_minimal()   # clean, modern — good for presentations
# p_base + theme_light()     # soft gray gridlines
# p_base + theme_void()      # no axes, grid, or background — for maps and art
```

**Guidance:** `theme_bw()` is a safe default for academic papers. `theme_minimal()` is often preferred for presentations and web reports. Avoid the ggplot2 default (`theme_gray()`) for finished output — the gray panel background doesn't photocopy or print well.

## Customising a Theme {-}

Any theme element can be overridden with `theme()`:

```{r theme_custom_dataviz, message=FALSE, warning=FALSE}
ggplot(pdat, aes(x = Date, y = Prepositions, color = GenreRedux)) +
  geom_point(alpha = 0.6, size = 2) +
  theme_bw() +
  theme(
    legend.position  = "bottom",
    plot.title       = element_text(size = 14, face = "bold"),
    plot.subtitle    = element_text(size = 11, color = "gray40"),
    axis.title       = element_text(size = 12),
    panel.grid.minor = element_blank()
  ) +
  labs(title = "Preposition frequency over time, by genre",
       subtitle = "Legend moved to bottom; minor gridlines removed",
       color = "Genre")
```

Common adjustments:

- `legend.position = "bottom"` / `"top"` / `"none"` / `c(0.1, 0.9)` for a specific location
- `axis.text.x = element_text(angle = 45, hjust = 1)` to rotate x-labels
- `panel.grid.minor = element_blank()` to remove minor gridlines
- `strip.background = element_rect(fill = "gray90")` to style facet labels

# Saving Plots {#sec-dataviz-saving}

`ggsave()` saves the most recently displayed plot (or a named plot object). It infers the format from the file extension:

```{r ggsave_dataviz, eval=FALSE}
# Save the last plot that was displayed
ggsave(
  filename = here::here("images", "prepositions_by_genre.png"),
  width    = 8,
  height   = 5,
  units    = "in",
  dpi      = 300
)

# Save a specific plot object
my_plot <- ggplot(pdat, aes(x = Date, y = Prepositions)) +
  geom_point() + theme_bw()

ggsave(
  plot     = my_plot,
  filename = here::here("images", "prepositions.pdf"),
  width    = 7,
  height   = 4
)
```

**Guidance by output type:**

| Use | Format | DPI | Notes |
|-----|--------|-----|-------|
| Journal paper | PDF or TIFF | 300+ | Vector (PDF) best for line art; raster (TIFF) for photos |
| Presentation | PNG | 150 | Keep file size reasonable for slides |
| Web / blog | PNG or SVG | 100–150 | SVG scales but not all platforms support it |
| LaTeX document | PDF | — | Vector; integrates cleanly |

**On dimensions:** keep aspect ratio similar to what you want in the final document. A plot squeezed from 10×6 inches into a 3-inch column will look cramped — resize at generation time, not at insertion time.

# Further Resources {#sec-dataviz-resources}

This chapter covered the core workflow for building and customising ggplot2 plots. Topics not covered here but worth exploring:

- **Combining plots** — the `patchwork` package lets you combine ggplot objects with `+`, `|`, and `/` operators
- **Text and annotations** — `geom_text()`, `geom_label()`, `annotate()`, and the `ggrepel` package for non-overlapping labels
- **Legend fine-tuning** — `guides()` for controlling multiple legends; `theme(legend.*)` for detailed styling
- **Advanced faceting** — `facet_grid()` for two-variable facets; `scales = "free"` for independent axes
- **Interactive plots** — `plotly::ggplotly()` converts a ggplot into an interactive HTML widget
- **Themes and extensions** — the `ggthemes` package has journal-specific themes (Economist, FiveThirtyEight, etc.)

**Recommended references:**

- @wickham2016r — *R for Data Science* (free online at [r4ds.hadley.nz](https://r4ds.hadley.nz/)) has a thorough visualisation chapter
- The `ggplot2` book by Hadley Wickham is the definitive reference
- The R Graph Gallery ([r-graph-gallery.com](https://www.r-graph-gallery.com)) has hundreds of examples with full code
